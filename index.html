Auto-detect buildings (Jeffco Assessor data)

Queries Jefferson County's live parcel/assessor feed for the actual recorded building size (not a guess from imagery), pulls the full owner/parcel record with it, and flags anything at or above your threshold. It still can't know which already have a dot on the sandbox map — check each flagged one there before logging it as missing. Several parcels at one address usually means a condo/HOA complex — the popup lets you search Colorado's Secretary of State for the association's registered agent before you log it, per the condo protocol.

Local building footprints (your buildings.geojson)

Loads the county-wide building outlines from the buildings.geojson file you exported, straight from this page — no per-view querying needed. Each outline starts with just address/PIN/size; click one to fetch its full assessor record (owner, floors, subdivision, etc.) the same way the live scan does. Only buildings at or above your threshold are shown. This only works when the page is served over http/https (e.g. GitHub Pages) with buildings.geojson sitting next to index.html in the same repo — it can't load from a double-clicked local file.
